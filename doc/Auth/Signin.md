# 🔑 Como Fazer Login (Sign In)

Esta tela é a porta de entrada para os usuários já cadastrados no ecossistema Nexora BJJ. 

---

## 🧭 Como Usar a Tela de Login

### 1. Acesso por E-mail e Senha
Para acessar a plataforma com suas credenciais de cadastro:
1. **E-mail:** Digite o e-mail cadastrado na sua conta no campo **E-mail**.
2. **Senha:** Digite a sua senha no campo **Senha**. 
   * *Dica:* Você pode clicar no ícone do olho no canto direito do campo para exibir ou ocultar os caracteres da senha digitada.
3. **Lembrar de mim:** Marque esta caixa de seleção caso queira que o navegador salve suas informações de acesso para logins futuros (evitando ter que digitar o e-mail a cada nova sessão).
4. **Botão Entrar:** Clique no botão **ENTRAR** para autenticar. Caso os dados estejam corretos, você será redirecionado para a tela principal (Nexora Hub).

### 2. Acesso Rápido com Redes Sociais
Caso o recurso esteja disponível e configurado, você pode acessar a plataforma utilizando contas externas:
* Clique no botão correspondente da rede social (ex: **Google**) para fazer login instantaneamente sem precisar digitar a sua senha local.

### 3. Links Rápidos de Navegação
* **Esqueceu sua senha?:** Clique neste link caso tenha perdido sua senha e precise recuperá-la. Você será direcionado para a tela de recuperação de acesso.
* **Criar Conta:** Caso ainda não possua um cadastro, utilize o botão de criação de conta no topo ou no rodapé para ir para o formulário de cadastro.
